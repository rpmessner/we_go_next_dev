# Live catalog sync flow

`RulesetFlow.tla` (filename retained for links) checks the two-stage operation in
`Rules.SyncFlow` and its database adapter, `Rules.sync_raid_mechanics/2`.
The former [ruleset lifecycle](../ruleset-lifecycle/README.md) is retired.

## Contract

- Sync writes code-defined criteria directly to `gold.dim_mechanic_criterion` in
  one transaction, serialized against other syncs. Unlisted definitions become
  inactive; their ids, stable keys and attached facts remain.
- The default `current_tier` aggregate owns the whole catalog. Single-raid sync
  retires only that raid's boss-scoped rows; it leaves other raids untouched.
- `--rebuild` requests exactly sync → rebuild. No activation/promotion flags exist.
- Success returns `criteria`, `rebuild`, and `completed`. A failure returns
  `stage`, `completed`, `reason`, and the successful stages' `result`.
- Sync remains committed if rebuild fails. Batch rebuild errors identify the
  completed, failed and remaining encounters. Retry the command after repair.
- Each coordinated pull rebuild keeps facts/document consistency through the
  freshness partial marker and output transaction (we-g18.6).
- Optional `valid_from` / `valid_until` are UTC instants: inclusive start,
  exclusive end, tested against the pull start, not hit time. Missing pull time
  matches undated definitions only. Undated stable keys are unchanged.

## TLC evidence

8 states / 11 steps; all seven invariants and NoDeadlock hold. The replacement
model found no new counterexamples. It checks completed-prefix ordering,
explicit failure, rebuild-after-sync, completion of requested work, retirement,
key attachment and preservation of facts until rebuild. Exhaustive event-prefix
tests replay the pure flow properties; integration tests replay retirement and
fact preservation. The pre-collapse default-to-draft bug is obsolete because no
status column/table or status-writing adapter remains.

The chart hides five steps staying in the same displayed state. SQL and file
failures are nondeterministic failed stages; crashes, concurrent rebuild/sync
interleavings, full mechanic contents and date arithmetic are outside this small
model. Date-window behavior and real-log fact values are integration-tested.

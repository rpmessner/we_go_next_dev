# Q2: Were we improving across the Sszorak pulls, and on which mechanics?

Status: draft, awaiting operator verification.

## Pull choice

All Sszorak pulls in log 30, gold pulls 436 through 444, including resets.

## Reference answer

The raid eventually kills Sszorak, but progress is not monotonic. The long pull 5 reaches an observed minimum of 17.708% HP, then pulls 6, 7, and 8 reach 67.199%, 43.993%, and 91.665%. Pull 9 is the kill. Pulls 1, 2, 4, and 8 last less than a minute and must not be treated as full mechanic samples. No failure facts exist for these pulls. No active-ruleset criterion applies to Sszorak in this snapshot. Arcane Expulsion (1214081) and Void Burst (1269183) belong to the archived seed ruleset, so they do not establish current coverage.

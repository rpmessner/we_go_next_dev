Names come from `players` in the SQL query and [spell-names.json](evidence/spell-names.json), collected from bronze spell prefixes.

Silver deaths and damage taken, gold pull dimensions, failure facts, and criterion rows are read-only inputs. Where present, boss HP samples come from bronze advanced damage blocks, matched to the boss name and info GUID.

## Grading notes

Require one private, prioritised, evidenced note per player. Alternate coaching priorities are acceptable if supported. Do not reward confident blame for unruled ambient damage, tank attacks, or a passive self-damage blow. Keep recommendations labelled as inference.

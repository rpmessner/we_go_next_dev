Status: revision 2 (after we-6l9 Feign Death fix), awaiting operator verification.

## Reference answer

The preceding damage is Ula'tek's Presence pulses and Viscous Cyst hits, shown below. There is no matching stored avoidable rule for these spells. Avoidability is unknown from the authored mechanic rules, not established as either avoidable or unavoidable. [440, silver.death and gold.dim_mechanic_criterion]
